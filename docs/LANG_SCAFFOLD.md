# Language Scaffold Command Guide

## 📌 Descripción General

El comando `lang:scaffold` genera automáticamente archivos de idioma (`LandingPage.php`) con una estructura completa y lista para completar. Es ideal para:

- ✅ Crear landing pages en nuevos idiomas rápidamente
- ✅ Mantener consistencia en la estructura de traducciones
- ✅ Preparar archivos para traducción manual o automatizada
- ✅ Integración futura con dashboards y sistemas de IA

---

## 🚀 Uso Básico

### Comando Simple (Idiomas Configurados)

```bash
php spark lang:scaffold
```

**Qué hace:**
- Lee los idiomas de `app/Config/App.php` → `$supportedLocales`
- Genera `LandingPage.php` para cada idioma (si no existen)
- Crea 4 preguntas FAQ por defecto
- Muestra resumen de archivos creados/omitidos

**Ejemplo de salida:**
```
Scaffolding language files for: es, en, pt, it, fr
FAQ questions per locale: 4

✓ es: File exists (use --force to overwrite)
✓ en: File exists (use --force to overwrite)
⊘ pt: File exists (use --force to overwrite)
⊘ it: File exists (use --force to overwrite)
⊘ fr: File exists (use --force to overwrite)

Skipped: 5
  es, en, pt, it, fr

✓ Language scaffold generation complete.
```

---

## 🎛️ Opciones Disponibles

### `--languages` 
Especifica qué idiomas scaffoldear (override de configuración)

```bash
php spark lang:scaffold --languages de,ja,ko
```

**Ejemplo de uso:**
```bash
# Scaffoldear un solo idioma
php spark lang:scaffold --languages de

# Scaffoldear múltiples idiomas
php spark lang:scaffold --languages es,en,fr,de,ja,pt,it

# Idiomas con código largo
php spark lang:scaffold --languages es-MX,en-US,pt-BR
```

**Resultado:**
```
Scaffolding language files for: de, ja, ko
FAQ questions per locale: 4

✓ de: Created
✓ ja: Created
✓ ko: Created

Created: 3
✓ Language scaffold generation complete.
```

---

### `--faq-count`
Define cuántas preguntas FAQ incluir en la estructura (default: 4)

```bash
php spark lang:scaffold --faq-count 6
```

**Ejemplo de uso:**
```bash
# Scaffoldear con 3 preguntas
php spark lang:scaffold --faq-count 3

# Scaffoldear con muchas preguntas (para proyectos grandes)
php spark lang:scaffold --faq-count 10

# Combinado con --languages
php spark lang:scaffold --languages de,fr --faq-count 5
```

**Resultado:** El archivo generado incluye exactamente N preguntas vacías con estructura normalizada.

---

### `--force`
Sobreescribe archivos existentes (útil para regenerar estructura)

```bash
php spark lang:scaffold --force
```

**Ejemplo de uso:**
```bash
# Regenerar todos los idiomas configurados
php spark lang:scaffold --force

# Regenerar un idioma específico con más preguntas
php spark lang:scaffold --languages es --faq-count 8 --force

# Overwrite parcial de idiomas nuevos
php spark lang:scaffold --languages en,de --force
```

**Salida:**
```
Scaffolding language files for: es, en
FAQ questions per locale: 4

⟳ es: Overwritten
⟳ en: Overwritten

Overwritten: 2
  es, en

✓ Language scaffold generation complete.
```

⚠️ **Precaución:** `--force` reemplaza archivos completos. Los cambios previos se pierden. Hacer backup si es necesario.

```bash
# Agregar nuevo idioma a Config\App::$supportedLocales primero
```

```bash
# Crear estructura para 6 idiomas con 5 preguntas FAQ
```

```bash
# Proyecto existente con 4 preguntas, necesita 8

php spark lang:scaffold --languages es,en --faq-count 8 --force
```

**Qué ocurre:**
- Reemplaza `es/LandingPage.php` con 8 preguntas vacías
- Reemplaza `en/LandingPage.php` con 8 preguntas vacías
- Mantiene otros idiomas intactos

```bash
# Ejecutar después de actualizar Config\App::$supportedLocales

php spark lang:scaffold --faq-count 6
```

**Crea todos los idiomas configurados con 6 preguntas cada uno.**

## 🎯 Estructura FAQ Normalizada

La estructura FAQ generada es completamente flexible:

```php
'questions' => [
    [
        'question' => 'Tu pregunta aquí',
        'answer' => [
            'intro'    => 'Párrafo introductorio',
            'benefits' => [
                'Beneficio 1',
                'Beneficio 2',
                'Beneficio 3',
            ],
            'outro'    => 'Párrafo de cierre (opcional)',
        ],
    ],
]
```

### Cómo completar cada pregunta

**Opción A: Respuesta simple (solo intro)**
```php
'answer' => [
    'intro'    => 'Esta es mi respuesta completa...',
    'benefits' => [],           // Array vacío
    'outro'    => '',          // String vacío
],
```

**Opción B: Respuesta con lista de beneficios**
```php
'answer' => [
    'intro'    => 'Aquí están las características:',
    'benefits' => [
        'Beneficio 1',
        'Beneficio 2',
        'Beneficio 3',
    ],
    'outro'    => 'En conclusión...',
],
```

**Opción C: Respuesta con intro y outro (sin beneficios)**
```php
'answer' => [
    'intro'    => 'Primer párrafo...',
    'benefits' => [],
    'outro'    => 'Segundo párrafo...',
],
```

## 📋 Workflow Completo: De Cero a Landing Multiidioma

### Paso 1: Configurar Idiomas

Editar `app/Config/App.php`:

```php
public array $supportedLocales = ['es', 'en', 'fr', 'de'];
```

### Paso 2: Generar Estructura

```bash
php spark lang:scaffold --faq-count 5
```

**Resultado:**
- `app/Language/es/LandingPage.php` (vacío)
- `app/Language/en/LandingPage.php` (vacío)
- `app/Language/fr/LandingPage.php` (vacío)
- `app/Language/de/LandingPage.php` (vacío)

### Paso 3: Completar Traducciones

Editar cada archivo y llenar los valores:

```php
// app/Language/es/LandingPage.php
'meta' => [
    'title' => 'NewsLanding - Plantilla de Landing Page de Suscripción',
    'description' => 'Conecta con los mejores profesionales...',
    // ...
],
```

### Paso 4: Probar en el Navegador

```bash
php spark serve
# Navegar a http://localhost:8080/es
# Navegar a http://localhost:8080/en
# Etc.
```

## 🔄 Integración con Dashboard Futuro

El comando prepara los archivos para una app externa:

✅ **Metadata parseable:** Los comentarios `// Generated by` permiten detectar archivos autogenerados  
✅ **Estructura consistente:** Todas las secciones siguen el mismo patrón  
✅ **FAQ flexible:** Soporta N preguntas con estructura normalizada  
✅ **PHP puro:** Los arrays se pueden serializar a JSON fácilmente  

**Ejemplo de integración:**
```php
// En tu app externa (dashboard)
$scaffoldContent = file_get_contents('app/Language/es/LandingPage.php');
$content = eval('?>' . $scaffoldContent); // Ejecuta el PHP
$json = json_encode($content, JSON_PRETTY_PRINT);
// Ahora puedes editar en UI y guardar de vuelta
```

## ❓ Preguntas Frecuentes

### P: ¿Qué pasa si el archivo ya existe?
**R:** El comando lo omite y muestra `⊘ {locale}: File exists`. Usa `--force` para sobreescribir.

### P: ¿Debo commitar los archivos generados?
**R:** Sí, son archivos fuente. Después de generar, completa los valores y commitea.

### P: ¿Puedo cambiar la estructura después de generar?
**R:** Sí, la estructura es flexible. Si quieres agregar campos nuevos a futuro, hazlo manualmente en los archivos.

### P: ¿Qué pasa si cambio `$supportedLocales` después de generar?
**R:** Los archivos viejos quedan intactos. Ejecuta de nuevo sin `--force` para generar solo los nuevos idiomas.

### P: ¿Cómo regenero un idioma si cometí errores?
**R:** 
```bash
# Opción 1: Editar manualmente el archivo
# Opción 2: Usar --force para regenerar desde cero
php spark lang:scaffold --languages es --force
```

### P: ¿Puedo tener diferentes números de preguntas por idioma?
**R:** No directamente con el scaffold. El comando aplica el mismo `--faq-count` a todos los idiomas. Edita manualmente después si necesitas diferencias.

### P: ¿Dónde se guardan los archivos?
**R:** En `app/Language/{locale}/LandingPage.php`. La ruta es fija según CI4 standard.
